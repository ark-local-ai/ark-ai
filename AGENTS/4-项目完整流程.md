## 一、一次任务的完整流程（运行时视角）

### 阶段 0：用户触发
用户在首页 `Home.tsx`：
- 可直接在输入框打字；
- 或点**场景胶囊** → 下拉选**参考提示词** → 自动回填输入台 + 打上可移除标签。

无论哪条路，最终输入台都有一段 prompt 文本，用户按 Enter 或点发送。

### 阶段 1：创建任务（前端 → 后端）
1. `Home.submit()` 调 `api.createTask(prompt)` → `POST http://127.0.0.1:5173/api/tasks`（Vite 代理转发到 `:4000`）。
2. `routes/tasks.ts` 用 `randomUUID` 生成 `taskId`，**立刻返回 `{taskId}`**，并后台 `void runTask(id, prompt)`。
3. 前端拿到 id 后 `nav("/app/task?taskId=xxx")`，任务页**瞬时打开**（不等后端执行）。

### 阶段 2：编排执行（后端，异步）
`orchestrator.runTask` 在后台跑：
1. 写库：`insertTask`（含初始验收清单）+ 4 条 `insertStep`。
2. 置 `running`，广播 `plan` 事件。
3. 逐条步骤（每条约 0.9s 模拟）：
   - 标 `running` → 广播 `step`
   - 最后一步：**写真实 .md 文件**到 `frontend/public/workspace/` → 标 deliverable → 广播 `deliver`
   - 标 `done` → 广播 `step`
   - 逐步更新验收清单 → 广播 `check`
4. 全步骤完成：置 `done`，写回最终 checks/timeline，广播 `check` + `done`。

### 阶段 3：前端实时点亮（SSE + 快照）
`TaskPage.tsx`：
- 挂载时 `getTask(id)` 拉一个**快照**打底（即使 SSE 已经播完也能显示完整状态）。
- 同时 `EventSource` 订阅 `/events`，按事件：
  - `plan` → 初始化步骤列表
  - `step` → 点亮对应步骤（running/done）
  - `deliver` → 交付卡片出现
  - `check` → 右侧验收清单打勾
  - `done` → 状态徽标置「已完成」

### 阶段 4：成果交付
任务完成 → 右下交付卡出现成果文件（`.md`），点「下载」→ `GET /api/workspace/<文件名>` → `createReadStream` 返回文件 → 浏览器下载。

## 二、SSE 事件协议（前后端约定）

| 事件 type | 载荷 data | 触发时机 |
|---|---|---|
| `plan` | `TaskStep[]` | 任务开始，下发完整步骤计划 |
| `step` | `{ stepId, status }` | 每步状态变化 |
| `deliver` | `{ name, kind, note, path }` | 生成交付文件 |
| `check` | `[{label, ok}]` | 验收清单更新 |
| `done` | `{ taskId }` | 全部完成 |
| `error` | `{ message }` | 出错（预留） |

## 三、开发流程（本周我如何把这套系统搭起来）

1. **读现状**：项目原本是纯前端 mock。我读了 `ARCHITECTURE.md`、`docs/建造计划_PLAN.md`、`docs/功能模块规格书_MODULES.md`，确认后端是规划中的坑位。
2. **定技术栈**（与你商量后按默认推进）：Node 22 + TS + Fastify + node:sqlite；先跑通任务闭环再接真 LLM。
3. **搭后端骨架**：`apps/backend` 建 package.json/tsconfig/目录。
4. **装依赖踩坑**：better-sqlite3 原生编译失败 → 换 Node 内置 node:sqlite（详见踩坑日志 7）。
5. **写存储层** → **事件总线** → **编排层** → **路由** → **入口**，每写完一层就 `tsc` 校验。
6. **API 自测**：curl 建任务、查快照、抓 SSE 事件流，确认全链路。
7. **前端接线**：写 `api.ts`，改 `Home.submit` 和 `TaskPage`，跑 `npm run build` 校验类型。
8. **端到端验证**：后端 + 前端双启动，用 vite 代理从 :5173 发请求，确认 SSE 走代理也通、文件落盘、checks 全绿。
9. **GUI 实测**：浏览器打开工作台，确认 UI 渲染；交互注入受工具限制（详见排查日志 9）。
10. **写文档**：本目录 9 份，同步每个决策与进度。
