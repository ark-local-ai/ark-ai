## 三、架构决策备忘（详见 8-变化原因）
- **后端**：Node 22 + TS + Fastify + 内置 `node:sqlite`（零编译，Windows 友好）。
- **编排**：先自写状态机，留 `plannerLLM` 接入点，按需演进（不提前上 LangGraph）。
- **进度推送**：SSE（单向持续推送 + replay 缓存）；M21 起有全局事件流（/api/events）供任意页通知。
- **LLM**：openai 兼容 fetch adapter，零依赖，DeepSeek/OpenAI/Ollama 通吃；M14 起 chatWithFailover 按成功率逐个试所有渠道，M15 加权（可靠性/延迟/成本/优先级），M27 加每个渠道熔断（5 次失败 open + 10s cooldown + half-open 探测）。
- **Office 交付**：pptxgenjs / exceljs / docx（全 JS，零原生编译），按需求关键词选类型，产出可编辑真实文件。
- **模型路由**：router 按渠道综合评分选优，统计写 SQLite；坏渠道自动降权 + 熔断短路。
- **验收/重试**：verifier 对交付文件做真实校验（存在/非空/zip），失败限次重试。
- **工作空间**：`GET /api/workspace` 真扫 `frontend/public/workspace/`，按类型/大小/时间列出；M20 起文件名 FTS5 trigram 全文搜索（Cmd+K 搜文件）。
- **对话流式**：`POST /api/chat` SSE 逐 token 推送；配 key 走真实模型 `chatStream`，无 key 走内置回复逐字流式降级；M19 起会话落库持久化、M23 起对话内容全文搜索。
- **自动化**：`scheduler/jobs.ts` 本地 Cron（jobs/job_logs 表），30s 轮询匹配「每天 HH:MM / every:N 分钟」到点调 runTask 并记日志；同分钟防重。
- **模型渠道**：DB 持久化（channels 表，env 引导种子），CRUD + 验活（GET /models）+ 设默认；router/planner 直接消费 DB 渠道。
- **连接器**：`GET /api/connectors` 真实状态——渠道计数 + Ollama 探测（GET /api/tags），未接入的如实标未接入（不假在线）。
- **场景库**：`GET /api/scenarios`（`data/scenarios.ts` 6 场景），首页/提示词库共用；前端 `listScenarios` 拉取（mock 仅离线降级）。
- **任务执行可靠性（M16 起）**：M16 串行队列（runner.ts 模块级 Promise 链）→ M30 改信号量受控并发（默认同跑 2，ARK_MAX_CONCURRENCY 覆盖，FIFO 排队）+ 失败兜底（异常→failed+error，不卡 running）；M17 重试/删除；M24 进程重启恢复；M31 断点续跑（resumeTask）；M26 任务 ID 贯穿日志。
- **测试（M25 起）**：vitest（ARK_DB_PATH/ARK_TEST 隔离临时库，绝不碰真实 data/ark.db），store/events/runner/HTTP 7 文件 68 用例，npm test / typecheck(tsconfig.test.json) / build 三件套全绿。
- **认证（M36 起）**：写请求硬门禁（`routes/guard.ts` 根 preHandler：POST/PUT/PATCH/DELETE→`/api/*` 需登录 401，读开放；`/api/auth/*` 自管）；`ARK_REQUIRE_AUTH=0` 回退软门禁（本地单机/演示）。前端全部写调用已带 `authHeaders()`。
- **自动清理（M32 起）**：tasks.created_ts 存 epoch ms（created 是 zh-CN 本地化字符串不可排序）；`maintenance/cleanup.ts` 按龄删终态非归档任务的交付文件并从库清除，审计日志裁剪到 AUDIT_MAX；安全护栏 safeUnlink 只删工作目录内文件防路径穿越；`POST /api/maintenance/cleanup` 手动触发，调度器每 6h 自动，env 可开关/调留存。
- **任务模板（M33 起）**：`task_templates` 表（name/desc/prompt + 可选的 expert/skills/model）多用户隔离 CRUD + `POST /:id/run` 一键应用模板建任务（复用 enqueueTask 同管线）；前端 `/app/templates` 页（列表/新建/编辑/删除/应用并执行）。
