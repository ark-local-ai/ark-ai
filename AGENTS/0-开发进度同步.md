## 二、正在开发什么

- **已刚完成**：真实 Office 交付（M4）——`tools/office.ts` 按需求关键词（PPT/Excel/Word）用 pptxgenjs/exceljs/docx 生成**可编辑真实文件**到 workspace，orchestrator 最后一步调用。实测三场景（PPT/Excel/Word）均产出正确类型、可下载、有效 zip。产品核心卖点「一句话 → 交付可编辑办公文件」已兑现。
- **正在做**：把交付文件在任务页的「整理/归档」与下载体验打通（工作空间页 M7），以及对话流式（M5）。

## 三、架构决策备忘（详见 8-变化原因）
- **后端**：Node 22 + TS + Fastify + 内置 `node:sqlite`（零编译，Windows 友好）。
- **编排**：先自写状态机，留 `plannerLLM` 接入点，按需演进（不提前上 LangGraph）。
- **进度推送**：SSE（单向持续推送 + replay 缓存）。
- **LLM**：openai 兼容 fetch adapter，零依赖，DeepSeek/OpenAI/Ollama 通吃。
- **Office 交付**：pptxgenjs / exceljs / docx（全 JS，零原生编译），按需求关键词选类型，产出可编辑真实文件。
