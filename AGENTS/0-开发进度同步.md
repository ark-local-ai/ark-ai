## 二、正在开发什么

- **已刚完成**：真实 LLM planner（M3）——配了渠道走 openai 兼容拆真步骤，没配 key 走**场景化脚本计划器**（PPT/Excel/Word/调研各自差异化步骤）。orchestrator 用它规划，交付文件嵌入规划步骤，`task.model` 标记「LLM/内置计划器」。
- **正在做**：把交付从 .md 升级为**真实可编辑 Office 文件**（pptxgenjs / ExcelJS / docx），这样才算兑现「一句话 → 交付可编辑 PPT/Excel/Word」的核心卖点。

## 三、架构决策备忘（详见 8-变化原因）
- **后端**：Node 22 + TS + Fastify + 内置 `node:sqlite`（零编译，Windows 友好）。
- **编排**：先自写状态机，留 `plannerLLM` 接入点，按需演进（不提前上 LangGraph）。
- **进度推送**：SSE（单向持续推送 + replay 缓存）。
- **LLM**：openai 兼容 fetch adapter，零依赖，DeepSeek/OpenAI/Ollama 通吃。
